# fnyys 的 Muvyo 插件

Muvyo 第三方插件仓库。在 Muvyo「第三方插件 → 插件仓库」添加本仓库地址，就能在列表里安装下面的插件。

## 插件列表

都是资源搜索类插件，在 Muvyo 的资源搜索、订阅和机器人里使用。

| 插件 | 说明 | 需要准备 |
|---|---|---|
| 癫影（`fnyys6694-arch.dian115`） | 按作品搜索 115 分享、磁力与电驴资源；需要积分的资源点「获取链接」后解锁，支持每日签到与转盘 | 搜索及 OpenAPI 签到需 Key（需有效 VIP）；仅 Telegram 签到、转盘无需 Key |
| 观影（`fnyys6694-arch.guanying`） | 搜索 115、光鸭、123 网盘分享和磁力资源，自动过站点验证并登录 | 观影站账号和当前可用的站点地址 |
| 影巢（`fnyys6694-arch.hdhive`） | 搜索影巢资源，需要积分的点「获取链接」后解锁；支持每日签到、发布者白名单，转发频道资源卡片给机器人可直接转存 | 影巢授权（设置页内一键打开授权页） |
| 盘搜（`fnyys6694-arch.pansou`） | 搜索 115、百度网盘、天翼云盘的分享和磁力资源 | 自己部署的 [PanSou](https://github.com/fish2018/pansou) 服务 |
| SeedHub（`fnyys6694-arch.seedhub`） | 搜索 SeedHub 磁力资源，交给支持离线下载的网盘或 BT 下载器；转发频道卡片给机器人可解析磁力 | 自己部署的 [FlareSolverr](https://github.com/FlareSolverr/FlareSolverr) |
| Telegram 频道（`fnyys6694-arch.telegram`） | 搜索填写的公开频道及勾选的频道、群组，可调用搜索机器人；打开实时监听后，频道一有新资源就交给订阅 | 读取私有频道和群组时，先在 Muvyo 登录 Telegram 账号 |

每个插件的详细设置和更新记录见插件详情页。

# 影巢

用你的影巢授权，在 Muvyo 的资源搜索、订阅和机器人里搜索影巢资源。需要积分的资源点「获取链接」后才解锁；支持每日签到（插件设置 → 定时任务）。

## 授权

- **新授权**：点设置页上方「打开影巢授权页」，同意后浏览器会跳到一个打不开的 `http://127.0.0.1/?code=…` 页面，这是正常的；把地址栏里 `code=` 后面的内容（或整个地址）粘贴到「授权码」并保存，下次搜索时插件自动换成授权。
- 授权失效时插件会提示重新授权：重新获取授权码填入即可。

## 过滤与签到

- **只要官组和白名单发布者** / **发布者白名单**：打开或填了后，手动搜索、订阅、机器人都只保留官组和白名单发布者的资源。
- **赌狗签到**：定时签到时用赌狗模式。签到任务在插件设置的「定时任务」里打开。

## 自建应用（可选）

留空用插件自带的应用。在影巢注册了自己的 OpenAPI 应用时填 Client ID 和 Secret；这时授权页链接里的 client_id 要换成你自己的。

## 转发资源卡片

把影巢频道的资源卡片转发给 Muvyo 的机器人，卡片里的「直达链接」会交给插件处理。卡片写了 TMDB 编号时，插件先只读查出这条资源要几分；免费的直接获取链接并转存，要积分或查不到要几分的，机器人先问你，回复 `y` 才解锁扣分。解锁出来是磁力或电驴链接时，交给离线下载。

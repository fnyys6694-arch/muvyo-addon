# 盘搜

连接你自己部署的 [盘搜（PanSou）](https://github.com/fish2018/pansou) 服务，在 Muvyo 的资源搜索、订阅和机器人里搜索 115、百度网盘、天翼云盘的分享和磁力资源。

## 设置

- **盘搜服务地址**：你部署的盘搜地址，例如 `http://192.168.1.100:8888`。局域网地址直接填。
- **用户名 / 密码**：盘搜开启了登录认证时填写；没开就留空。登录状态由插件保存，过期会自动重新登录。

装好后在插件设置里打开「参与订阅与洗版」，默认来源的订阅和洗版才会用它。访问公网服务时可经 Muvyo 已填写的系统代理，局域网服务仍按已确认的服务地址直连。

## 说明

- 只搜你自己的盘搜服务，插件不访问其他网站。
- 搜索结果的分享链接由 Muvyo 按已接入的网盘校验，认不出的会被丢弃。

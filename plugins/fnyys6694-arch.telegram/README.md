# Telegram 频道

搜索你填写的 Telegram 公开频道，以及你勾选的频道和群组（公开、私有均可）；打开「频道实时监听」后，频道一有新资源就交给 Muvyo：片名命中订阅的走订阅转存；在插件设置「插件推送的资源」里打开后，没命中订阅的也可以按作品转存、比较质量洗版或直接离线。

## 设置

- **公开频道**：频道用户名，每行一个，带不带 @ 都行。
- **可读取的频道和群组**：勾选就会读取，无需再打开额外开关。公开频道按用户名读取，与上方填写的同名频道只读一次。需要先在 Muvyo 的「Telegram 账号」登录。私聊读不到，群组消息不带发送人。
- **搜索机器人**：每行一个「机器人 | 方式 | 查询模板 | 详情按钮 | 翻页按钮」。方式有 query（发一条查询）、inline、history（只读历史回复）。机器人要先在插件设置下方「可用的搜索机器人」里添加；只点你写的详情、翻页按钮，购买、解锁、加入一类按钮一律不点。每次搜索最多问 2 个机器人。
- **公开频道读取方式**：自动模式先按剩余账号额度读取，给实际勾选的私有频道预留额度；账号不可用或额度不足时读网页版。网页版经 Muvyo 已填写的系统代理访问成功后，后续优先用网页。网页版连不上会记住约 10 分钟；单次调用快超时时交出已有结果。

## 频道实时监听

在插件设置的「定时任务」里打开，默认每 2 分钟运行一次：

- 是否在订阅允许时段外跳过，由 Muvyo 的「遵守订阅允许时段」开关控制，插件不再另设监听时段。
- 第一次运行只记下各频道当前的位置，不处理旧消息；之后每次读取上次之后的新消息。
- 消息里的网盘分享、磁力、电驴解析出来后交给订阅：只交给勾选了本插件的订阅，或者没限定来源、且本插件打开了「参与订阅与洗版」的订阅。片名命中才转存，过滤、去重、文件校验都按订阅原来的规则。
- 没有命中任何订阅的资源默认不转存；在插件设置「插件推送的资源」里打开「没命中订阅的资源也转存」后，由 Muvyo 认出作品、媒体库没有的转存到你配置的目录，可按频道指定目录、比较质量洗版、对认不出的链接直接离线。

## 用到的 Muvyo 服务

账号读取与排队也按本次搜索的剩余时间收尾。后续频道慢或队列繁忙时，已取得的资源仍会返回，并标明只完成了部分搜索。

- **读取 Telegram 频道**：用你在 Muvyo 登录的 Telegram 账号读频道消息。插件可能把读到的消息发到它获准访问的网站（本插件只访问 t.me、telegram.me）。
- **推送资源给订阅**：把找到的资源交给订阅，转不转存由订阅规则决定。

# SeedHub

经你部署的 [FlareSolverr](https://github.com/FlareSolverr/FlareSolverr) 打开 SeedHub，在 Muvyo 的资源搜索和订阅里搜索磁力资源，交给支持离线下载的网盘或 BT 下载器。

## 设置

- **FlareSolverr 地址**：SeedHub 有 Cloudflare 验证，要经 FlareSolverr 打开。填你自己部署的地址。地址只由 Muvyo 使用，插件连不到它。
- **站点**：主站打不开时换备用站点。
- **磁力解析条数**：每条磁力都要经 FlareSolverr 打开一次中间页，最多 3 条。
- **单页最长等待**：FlareSolverr 过一次验证的最长时间。

FlareSolverr 慢，建议把插件的「单次执行时限」调到 180 秒以上。搜索时按标题、年份、类型找唯一对得上的作品，对不上宁可不出结果，不会把别的作品的磁力送去下载。

## 转发频道卡片

把 SeedHub 频道的资源卡片转发给 Muvyo 的机器人，卡片按钮里的影片详情页会交给插件解析出磁力：只有一条时直接提交离线下载，有多条时回复序号选择。

# 癫影

用你的癫影 OpenAPI Key，在 Muvyo 的资源搜索、订阅和机器人里按作品搜索 115 分享、磁力与电驴（ed2k）资源。需要积分的资源点「获取链接」后才解锁；支持每日签到与转盘。

## 设置

- **OpenAPI Key**：癫影官网个人中心生成（需要有效 VIP）。
- **签到方式**：Telegram 机器人（要先在 Muvyo 的「Telegram 账号」里登录）或 OpenAPI（不抽转盘）。
- **签到模式 / 转盘抽数**：转盘只在 Telegram 方式、签到成功后执行，每抽都花积分。

签到在插件设置的「定时任务」里打开。

## 说明

- 只填关键词时，插件先用 Muvyo 配置的 TMDB 识别前 3 部作品再查资源；没配 TMDB 的话只能在选定作品后搜索。
- 解锁、签到这类会花积分的操作，结果不明时不会自动重试，请到官网核对。
- 电驴（ed2k）资源也参与自动订阅：解锁后按链接里的文件名核对是不是这部作品，核对不过时积分已经花掉、不会退回。
